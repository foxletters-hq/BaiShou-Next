## 填充协议（AI 生成时遵守）

1. **用户原话优先**：台词示例、称呼、关键设定，能用用户原话就用原话，不改写、不润色
2. **AI 提炼需标注**：从用户形容词/描述推导出的行为化内容，交付时在交付说明中列出「AI 提炼项」，让用户确认
3. **不擅自定义核心设定**：关系性质、essence、底线这三项如果采访没问清，必须追问，不得代拟
4. **缺项处理**：采访未覆盖的项，用「＿＿（待确认）」占位并在交付说明中列出，不编造
5. **机制默认保留**：沉浸要求、关系机制、harness 纪律除非用户明确修改，一律保留；thinking_mode 按采访结果填充（默认两条 + 用户加回项）
6. **生成后删注释**：所有 `<!-- -->` 说明在生成稿中删除，占位符全部替换
