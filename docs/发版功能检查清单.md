# 发版功能检查清单（Android / Windows）

> **用途**：发版前逐项确认「功能是否真的可用」，不是构建/签名/发布流程。  
> **流程检查**见 [发版检查SOP.md](./发版检查SOP.md)；本文只关注功能回归。  
> **规则**：P0 全部通过才允许发版；P1 至少覆盖本版改动模块；P2 时间允许再做。

---

## 0. 测试环境与数据准备

### 0.1 设备矩阵

| 平台    | 最低要求                | 建议补充                           |
| ------- | ----------------------- | ---------------------------------- |
| Android | 真机 arm64，Android 12+ | Android 14/15 各一台；覆盖安装旧版 |
| Windows | Windows 10/11 x64       | 干净虚拟机 + 已装旧版两套环境      |

### 0.2 测试数据

- [ ] 干净安装环境（无旧数据）
- [ ] 已安装**上一正式版**的升级环境
- [ ] 至少 2 个 Vault / 工作区
- [ ] 100+ 篇日记、跨月/跨年数据
- [ ] 1 个长会话（50+ 轮，含工具调用）
- [ ] 1 个知识库笔记本（含 PDF、图片、OCR 文档）
- [ ] 1 个可用 MCP Server（可选）
- [ ] 1 个可用 TTS Provider（可选）
- [ ] 网络环境：正常 / 断网 / 弱网 / 同局域网

### 0.3 标记说明

- **P0**：阻断发版，失败即 No-Go
- **P1**：核心功能，原则上必须通过
- **P2**：体验/边缘场景，记录问题但不阻断
- **A**：Android；**W**：Windows；**Both**：两端都测

## 1. P0 发版阻断清单

> 这一组全部通过，才进入详细回归。

- [ ] **P0-01 干净安装启动**：全新安装后能启动，无白屏/闪退/缺原生模块。
- [ ] **P0-02 覆盖升级**：上一正式版覆盖安装成功，数据保留，数据库迁移成功。
- [ ] **P0-03 版本号正确**：设置/关于页显示新版本；Android `versionCode` 大于旧版。
- [ ] **P0-04 引导/个人资料**：首次启动能完成语言、昵称、生日/性别等引导。
- [ ] **P0-05 对话主链路**：发送消息 → 流式回复 → 结束，内容正确。
- [ ] **P0-06 停止生成**：生成中点击停止，能立即停止且不写坏会话。
- [ ] **P0-07 工具调用**：至少一个工具（日记/搜索/总结/图谱/知识库）能成功调用并展示结果。

- [ ] **P0-09 日记写入**：通过对话或手动新建日记，保存后重启仍存在。
- [ ] **P0-10 总结生成**：能生成一篇周记/月报，内容来自真实日记。
- [ ] **P0-11 图谱打开**：记忆图谱/笔记本图谱能加载、搜索、打开节点详情。
- [ ] **P0-12 知识库导入**：导入 1 个文档，能完成解析/嵌入并可检索。
- [ ] **P0-13 同步往返**：两端各改一条数据，增量同步后双向一致，无重复/丢失。
- [ ] **P0-14 局域网传输**：一端发送、另一端接收成功，文件可打开。
- [ ] **P0-15 检查更新**：旧版能读到新版本并跳转正确下载地址。
- [ ] **P0-16 设置持久化**：模型/主题/语言/字体/背景设置重启后仍生效。
- [ ] **P0-17 无阻断崩溃**：上述路径中无崩溃、ANR、数据库损坏、启动死循环。

## 5. Agent Gate 权限门控

> 本版重点，建议单独安排 30 分钟专项。

- [ ] **D1（P0）默认询问**：触发受保护动作时弹出门控卡片，展示动作/风险/范围。
- [ ] **D2（P0）允许一次**：允许后动作执行成功；下一次同类动作仍按策略询问。
- [ ] **D3（P0）始终允许**：加入 allowlist 后同类动作不再询问；设置页可见并可移除。
- [ ] **D4（P0）拒绝**：拒绝后动作不执行，对话给出可理解的拒绝结果。
- [ ] **D5（P0）取消**：取消请求后不执行、不残留 loading、不重复弹窗。
- [ ] **D6（P1）排除列表**：危险动作即使在 full trust 下仍询问。
- [ ] **D7（P1）工作区安全模式**：切换安全模式后策略立即生效。
- [ ] **D8（P1）门控队列**：多个请求排队时，逐个处理；切换会话后状态正确。
- [ ] **D9（P1）Tab 徽标**：有待处理请求时伙伴 Tab 显示数量；处理完消失。
- [ ] **D10（P1）作用域隔离**：A 会话/工作区的 allowlist 不影响 B。
- [ ] **D11（P2）审计/记录**：门控决定有记录，重启后仍可追溯（若 UI 提供）。
