白守は、オープンソースでローカル優先の AI 記憶コンパニオンソフトです。

日記や暮らしの断片をローカルに書き溜めると、白守はそれを層ごとに要約して「思い出の年輪」にまとめ、AI パートナーが長期にわたって理解し、検索し、寄り添います。データはどこかのクラウドアカウントに入るのではなく、あなた自身の端末に残ります。

> 純白の誓いとともに、互いの一生を守る。

## できること

| 機能 | 説明 |
|------|------|
| 日記と思い出の年輪 | Markdown での記録を層ごとに凝縮し、週記・月報・季報・年鑑の長期記憶を形成 |
| 人生関係グラフ | 内蔵エンティティ関係グラフデータベースが人物ネットワークや時間の因果関係を自動整理 |
| 自律型 AI Agent | 計画立案とツール呼び出しを備え、オープンな MCP 規格で外部ツールエコシステムと連携 |
| 専属 AI パートナー | 複数のパートナーに個性や専用モデルを設定し、積み重ねた記憶の上で対話と寄り添いを実現 |
| ハイブリッド Graph RAG | 全文検索、ベクトル検索、グラフのマルチホップ推論を融合し、記憶を深く探索 |
| ワークスペースと同期 | 隔離されたマルチワークスペース、E2E 暗号化同期と自前の S3 / WebDAV バックアップに対応 |

:::tip[グラフデータベースと Agent 機能を正式実装]
白守は組み込みエンティティ関係グラフデータベースと自律型 AI エージェントシステムを包括的に導入しました。日々の記録だけでなく、日常の対話と断片化された記憶を対話的で推論可能な立体ネットワークへと昇華させます。
:::

## Notion・Obsidian との違い

ノートツールが解決するのは「資料をきれいに整えること」で、白守が解決したいのは「AI が本当にあなたを覚えていること」です。

| | ノートツール | 白守 |
|--|----------|------|
| 重心 | 整理、双方向リンク、執筆 | AI に長期的に理解され、使われる個人の記憶 |
| AI | プラグインや外付けのチャット欄が多い | パートナー、思い出の年輪、RAG が製品の骨格そのもの |
| データ | 公式クラウドやプラグイン生態に依存しがち | 既定はローカル。自前の S3 / WebDAV への同期も選べる |

## 私たちがこだわっていること

1. **ローカル優先**：コアデータはあなたの端末にあり、いつでもエクスポートして持ち出せます。
2. **コア機能は開放**：日記、自前同期、カスタムモデル API にペイウォールを設けません。
3. **AI が資料を読み解く**：検索も質問応答も要約もできます。単なるクラウドストレージではありません。
4. **公式サービスはあくまで選択肢**：楽をしたい人は使えますが、無課金でも変わらずフルに使えます。
