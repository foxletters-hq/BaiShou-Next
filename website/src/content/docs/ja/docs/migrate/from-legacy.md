---

旧 Flutter クライアントはメンテナンスを終了しており、現行製品は BaiShou-Next（デスクトップ Electron とモバイル Expo）です。

## モバイルのアップグレード方法

Android はパッケージ名が同じなら、新しい APK を上書きインストールするだけで済みます。ただし、上書きインストールはデータの移行が自動で終わったことを意味しません。アプリ内の **バージョン移行** を一度通す必要があります。

## バージョン移行の 3 原則

区画ごとに選んでインポートし、一度に全部流し込まないでください。

旧データディレクトリは削除しないでください。問題が起きたときに戻って確認できます。

順番を守ってください。特にチャット履歴はパートナーの後に回さないと、対応付けがずれやすくなります。

1. グローバルデータ：アバター、アイデンティティカード、設定
2. 各ワークスペースの日記
3. パートナー
4. チャット履歴

## 移行後にやること

1. 案内が出たらアプリを一度再起動します。
2. 日記とパートナーが揃っているか確認します。
3. [AI プロバイダーとモデル](/ja/docs/configure/ai-providers/) の設定ができているか確認します。
4. RAG ページで **未インデックス日記のフルスキャン** を実行します。引き継いだ日記は、通常ベクトル庫を作り直す必要があります。詳しくは [RAG 記憶管理](/ja/docs/configure/rag/) を参照してください。
5. [ローカルフルバックアップ](/ja/docs/sync/backup/) を 1 つ取ります。

## やってはいけないこと

移行が完全に終わるまで、旧ディレクトリを削除したりストレージを消したりしないでください。

「チャットできるようになった」を「RAG の準備ができた」と思わないでください。これは別の話です。

問題の報告は BaiShou-Next リポジトリへお願いします。旧リポジトリの Issues はもう見ていません。
