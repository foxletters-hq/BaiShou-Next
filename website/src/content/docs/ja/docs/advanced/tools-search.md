パートナーは会話のほかに、ツールを呼び出して日記を読み書きし、記憶を検索し、ウェブを検索できます。このページでは、どんなツールがあるのか、スイッチがどの層に隠れているのか、検索エンジンをどう選ぶのかを整理します。

## 内蔵ツール一覧

入口は **設定 → ツール管理** で、分類ごとに並んでいます。

| 分類 | ツール | 何をするか |
|------|------|--------|
| 日記 | 日記の読み取り | 日付を指定して全文を読む。1 回に最大 20 件 |
| 日記 | 日記の書き込み | 指定した日付に日記を新規作成する |
| 日記 | 日記の編集 | 追記または全文の上書き。既定は追記 |
| 日記 | 日記の削除 | 指定した日付の日記を削除する。復元できません |
| 日記 | 日記の一覧 | ある期間のうち日記がある日を列挙する |
| 日記 | 日記の検索 | ローカルの全文キーワード検索 |
| 要約 | 要約の読み取り | 週記・月報・季報・年鑑を読む |
| 記憶 | メッセージ検索 | セッションを横断して過去のチャット履歴を検索する |
| 記憶 | セマンティック検索 | ベクトルまたはハイブリッド検索で関連する断片を探す |
| 記憶 | 記憶の保存 | 内容を長期ベクトル記憶に書き込む |
| 記憶 | 記憶の削除 | セマンティックに一致させてから記憶を削除する |
| 検索 | ウェブ検索 | ウェブ検索。1 回に 1〜3 件のクエリを送れます |
| 検索 | ウェブページ読み取り | 指定した URL の本文を取得する |
| 一般 | 現在時刻の取得 | 実際の現在時刻を取得する。これはオフにできません |

ツール管理ページには **現在時刻** という項目もあります。これはツールではなく、システムプロンプトに現在時刻を自動で添えるかどうかだけを制御するもので、既定はオフです。

なお、スタンプの送信はツールではなくパートナーの能力で、スタンプ設定で管理します。

## スイッチは 4 層あります

「なぜうちのパートナーはこのツールを使ってくれないのか」は、ほぼこの 4 層のどこかが原因です。上から順に確認してください。

1. **ツール管理（グローバル）**：ここでオフにしたツールは、どのパートナーも使えません。
2. **パートナー種別**：仕事パートナーは日記・要約・記憶・セマンティック検索系のツールをすべて自動で無効にし、ウェブ検索、ウェブページ読み取り、時刻だけが残ります。これは設計上そうなっているのであり、バグではありません。詳しくは [AI パートナーと会話](/ja/docs/basics/companions/) を参照してください。
3. **RAG のスイッチと埋め込みモデル**：RAG をオフにするか埋め込みモデルが未設定だと、セマンティック検索と記憶の保存はそのまま使えません。
4. **セッション単位のウェブ検索スイッチ**：会話の入力欄にある検索ボタンです。これがオフだとウェブ検索ツールはモデルに渡されず、パートナーは「ウェブ検索がまだ有効になっていません。ツールバーで有効にしてから再試行してください」と返してきます。

4 層目が一番見落とされます。ツール管理のウェブ検索とは独立した別のスイッチなので、両方をオンにする必要があります。

## 検索エンジンの選び方

ウェブ検索の設定でエンジンを選びます。既定は Exa MCP で、キーなしで使えます。

| エンジン | API Key | 説明 |
|------|------------|------|
| Exa MCP | 不要 | 既定の選択肢。そのまま使えます |
| DuckDuckGo | 不要 | HTML の結果ページを取得します。ときどきレート制限を受けます |
| Tavily API | 必要 | AI 向けの検索 API |
| Exa API | 必要 | Exa の公式 API。MCP 経由より制御しやすいです |
| AnySearch API | 必要 | 中国国内向け。既定は中国語リージョン |
| Bing ローカル検索 | 不要 | ローカルブラウザで Bing の結果ページを取得。デスクトップのみ |
| Google ローカル検索 | 不要 | 同上。デスクトップのみ |

モバイルにはこの 2 つのローカル検索がなく、前の 5 つだけです。

主エンジンが失敗したとき、白守はキーを設定済みの他のエンジンへ自動でフォールバックして再試行します。ただし 2 つのローカル検索は失敗してもフォールバックせず、そのままエラーになります。

## 検索の調整できるパラメータ

| パラメータ | 既定 | 説明 |
|------|------|------|
| 最大結果数 | 5 | クエリごとに返す結果の数。上限 30 |
| ウェブページの RAG 圧縮 | オフ | 有効にすると取得したページをチャンクに分けて圧縮し、関連部分だけを残します |
| RAG 断片の総数上限 | 12 | 圧縮を有効にしたとき、1 回に残す断片の最大数 |
| 単一サイトの断片上限 | 4 | 1 つのサイトが枠を占め切るのを防ぎます |
| プレーンテキストの切り取り長 | 3000 | RAG 圧縮を使わないとき、ページごとに切り取る文字数 |

結果が少なすぎるときは最大結果数を上げてください。ページ内容でコンテキストが溢れるときは RAG 圧縮を有効にするか、切り取り長を小さくしてください。

:::note[検索は内容を外部に送ります]
検索リクエストはあなたが選んだ検索サービスへ送られ、取得したページ本文はモデルのコンテキストにも入ります。つまり追加の費用とプライバシーの露出が発生します。必要なときだけ有効にしてください。
:::

## TTS とスタンプ

**TTS 音声合成** では OpenAI 互換のインターフェース、Xiaomi MiMo、MiniMax、ローカルの GPT-SoVITS などを設定できます。設定後は会話でオフ、常に読み上げ、手動を選べます。

**スタンプ設定** ではスタンプパックを管理し、パートナーごとにどのパックを有効にするかを決めます。

## よくある失敗

| 症状 | 原因 |
|------|------|
| パートナーが「ウェブ検索がまだ有効になっていません」と言う | セッションのツールバーの検索スイッチがオフ |
| 検索が API key is missing or invalid を返す | キーが必要なエンジンを選んで未入力、または入力が誤っている |
| 埋め込みモデルが未設定で記憶を保存できないと表示される | グローバル既定モデルで埋め込みモデルを設定してください。[AI プロバイダーとモデルの設定](/ja/docs/configure/ai-providers/) を参照 |
| 日記のインデックスが未準備と表示される | RAG ページでフルスキャンを一度実行してください。[RAG 記憶管理](/ja/docs/configure/rag/) を参照 |
| パートナーがツールをまったく呼ばない | モデル自体が function calling に対応していない可能性が高いです。ツール呼び出しに対応したモデルに変えてください |
| ウェブページ読み取りが内容にアクセスできないと言う | 対象サイトがクロール対策をしているかログインが必要です。別の情報源に変えてください |
