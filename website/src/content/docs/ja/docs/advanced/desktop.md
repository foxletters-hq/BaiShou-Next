---
title: デスクトップ専用機能
description: グローバルショートカット、サイドバー管理、Git バージョン管理などデスクトップ機能。
---

以下の機能はデスクトップ（Electron）にのみあり、モバイルにはないか形が違います。完全な対比は [デスクトップとモバイルの違い](/ja/docs/reference/platforms/) を参照してください。

## グローバルショートカット

設定でグローバルショートカットを構成できます。たとえば既定では Alt+S でウィンドウの表示と非表示を切り替えます。他のアプリを使っている間でも呼び出せるので、思いついたことをその場で書き留めたいときに向いています。

## サイドバー管理

サイドバー項目の表示、非表示、並び順をカスタマイズできます。既定で表示されるのは日記、思い出、増分同期、バージョン管理などです。

## Git バージョン管理

デスクトップではストレージルートに対して Git の操作ができます。初期化、コミット、プッシュとプル、リモートと Token の設定、そして競合の処理です。

デスクトップを主庫として使い、履歴と誤操作のロールバックが欲しい人に向いています。[増分同期](/ja/docs/sync/incremental/) と組み合わせるのが最も効果的です。

:::tip[3 つの概念を混ぜないでください]
Git バージョン管理は増分同期ではなく、ZIP のフルバックアップでもありません。3 つの役割分担は [どれを使うべきか](/ja/docs/sync/overview/) を参照してください。
:::

## ローカル検索エンジン

デスクトップは Electron の隠しウィンドウを使って Bing と Google の結果ページを取得できるため、ウェブ検索に API Key の要らない **Bing ローカル検索** と **Google ローカル検索** の 2 つが増えます。モバイルにはありません。[ウェブ検索とツール](/ja/docs/advanced/tools-search/) を参照してください。

## その他

設定はサイドバーから入ることも、全画面の設定ページを開くこともできます。UI の詳細はバージョンによって変わります。

**白守について** にはバージョン情報、フィードバック入口、診断ログのエクスポートがあります。Issue を立てるときに診断ログを添えると、対応がぐっと速くなります。
