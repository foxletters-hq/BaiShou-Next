## 白守は無料ですか

コア機能は無料でオープンソースです。日記、自前同期、カスタムモデル API はペイウォールに依存しません。今後、公式がホストする同期・バックアップ・AI サービスが出た場合、それは選択肢です。詳しくは [プライバシーとオープンソース](/ja/docs/reference/privacy/) を参照してください。

## データはどこに保存され、安全ですか

既定はローカルの端末です。同期とバックアップはあなた自身が設定したリモートにしか行かず、AI リクエストもあなたが設定したモデル事業者にしか送られません。詳しくは [ワークスペースとデータの場所](/ja/docs/configure/workspace/) と [プライバシーとオープンソース](/ja/docs/reference/privacy/) を参照してください。

## どのプラットフォームに対応していますか

公式には Windows と Android があります。Linux は自分でビルドでき、iOS と macOS のクライアントは現在ありません。詳しくは [インストールと対応環境](/ja/docs/getting-started/install/) を参照してください。

## Notion や Obsidian との違いは何ですか

ノートツールは整理と執筆に重心があり、白守は「AI パートナー + 思い出の年輪 + RAG」という長期記憶に重心があります。詳しくは [白守とは](/ja/docs/getting-started/what-is-baishou/) を参照してください。

## モデルはどう設定しますか

画面を追いながら一度やるなら [10 分で話し始める](/ja/docs/getting-started/quick-start/) です。**設定 → プロバイダー管理** でプロバイダーを追加し、**グローバル既定モデル** で会話・要約・埋め込みのモデルをそれぞれ指定します。対照は [AI プロバイダーとモデル](/ja/docs/configure/ai-providers/) です。

## パートナーが書いた日記を覚えていません

まずパートナーの種別が親密パートナーであること、埋め込みモデルが設定済みであること、RAG に未インデックスの表示がないことを確認し、それからフルスキャンを一度実行してください。詳しくは [RAG 記憶管理](/ja/docs/configure/rag/) を参照してください。

## 増分同期とバックアップは混ぜて使えますか

同じしくみとして扱わないでください。クラウドパスも対象範囲も違います。詳しくは [どれを使うべきか](/ja/docs/sync/overview/) を参照してください。

## 思い出、共同の思い出、RAG の違いは何ですか

| 用語 | 一言でいうと |
|------|------------|
| 思い出の年輪 | 週記・月報・季報・年鑑。既定では各層がすぐ下の層だけを読みます |
| 共同の思い出 | 複数の層の要約を折りたたんで集約し、コピーも注入もできる内容 |
| RAG | 日記をベクトル化したセマンティック検索 |

詳しくは [回憶と共同回憶](/ja/docs/basics/memories/) と [RAG 記憶管理](/ja/docs/configure/rag/) を参照してください。

## 旧版からはどう移行しますか

上書きインストール後にアプリ内のバージョン移行を実行します。推奨順は [旧版白守からの移行](/ja/docs/migrate/from-legacy/) を参照してください。移行後は RAG を再スキャンするのを忘れないでください。

## データはエクスポートできますか

できます。Markdown エクスポート、フル ZIP バックアップ、自前の S3 や WebDAV への同期が使えます。プラットフォームに閉じ込めることはありません。

## クライアントに表示される費用は正確ですか

参考程度に考えてください。最終的にはモデル事業者の請求が正です。
