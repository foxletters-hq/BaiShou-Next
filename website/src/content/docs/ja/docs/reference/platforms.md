title: デスクトップとモバイルの違い
description: Windows デスクトップと Android モバイルのナビゲーション、機能、ストレージの違い。
---

両端は日記、思い出、パートナー、RAG、同期といったコア機能を共有します。違いは主に外側の枠と、いくつかの上級機能にあります。

## 対比

| 観点 | デスクトップ（Windows） | モバイル（Android） |
|------|------|-----------------|
| ナビゲーション | カスタマイズ可能なサイドバー | ボトムバー：日記 / パートナー / 思い出 / 設定 |
| Git バージョン管理 | あり | なし |
| MCP サービス | あり。旧版互換の `/sse` エンドポイントも別途あり | Android にもあり、`/mcp` のみ対応 |
| グローバルショートカット | あり | なし |
| 検索エンジンの選択肢 | 7 種類。Bing / Google ローカル検索を含む | 5 種類。ローカル検索はなし |
| 保存場所 | 任意のディレクトリ | アプリサンドボックス、または外部の `BaiShou_Root` |
| 公式パッケージ | Windows インストーラー | APK |

## どう組み合わせるか

主に書く作業をして Git を保険にしたいならデスクトップを使ってください。

断片的な記録とすぐ見返す用途はスマホが向いています。

同期方法の選び方は [どれを使うべきか](/ja/docs/sync/overview/) を参照してください。モバイルは片方向のバックアップとして使うか、双方向にするなら特に慎重に扱うほうが安全です。
