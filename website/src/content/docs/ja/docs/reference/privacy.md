## ローカル優先とはどういう意味か

日記とコアの業務データは、既定であなたの端末に保存されます。

あなた自身が設定したモデル API と同期・バックアップ先を除き、白守は基本機能のために日記を「白守の自社サーバー」へアップロードすることはありません。

## どんなときにデータが外に出るか

| あなたがしたこと | データの行き先 |
|------------|----------|
| AI と会話する、要約を生成する、埋め込みを作る | あなたが設定したモデル事業者 |
| ウェブ検索する | あなたが選んだ検索サービス。取得したページ本文はモデルのコンテキストにも入ります |
| 増分同期、クラウドバックアップ | あなたが設定した S3 / WebDAV |

いずれもあなたが自分で設定して初めて発生します。あわせて各事業者のプライバシーポリシーを読み、同期範囲も必要最小限にしておくことをおすすめします。

## 課金の考え方

コア機能は無料でオープンソースです。日記、自前同期、カスタムモデル API にペイウォールはありません。

今後、暗号化同期やホスト型バックアップ、公式 AI といった公式サービスを提供する場合、それは選択肢であり、公式サイトの案内に従って購入するものです。無課金でも変わらずフルに使えますし、データはいつでも持ち出せます。
