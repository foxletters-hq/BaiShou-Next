入口：桌面端在伙伴与对话区，移动端在底栏「伙伴」。

首次启动后会有一个默认伙伴 Latte，也就是看板娘。你可以再建更多伙伴，每个都有自己的人格和模型配置。Latte 的角色设定和出厂提示词见 [看板娘 Latte](/docs/basics/latte/)。

## 先搞清伙伴类型

建伙伴时要选类型，这个决定了它能不能碰你的日记。选错了会出现「为什么 TA 不能帮我写日记」这种困惑。

| | 亲密伙伴 | 工作伙伴 |
|--|----------|----------|
| 定位 | 陪伴、写日记、聊回忆 | 办事、讨论，尽量不碰隐私 |
| 日记工具 | 可读可写，前提是工具已启用 | 不能读写日记和记忆库 |
| 记忆与语义搜索 | 可用 | 相关工具被禁用 |

## 伙伴能配什么

- 名称、简介、头像（内置或自己上传）
- 系统提示词，也就是人格设定
- 绑定专用模型，不绑就用全局默认对话模型
- 设为默认、在侧栏置顶（桌面端）
- 上下文轮数，可以有限也可以无限
- 自动压缩：Token 阈值、保留轮数、压缩用的提示词
- 表情包组开关

## 对话里能做什么

会话管理方面：新建、重命名、查看和整理会话列表，随时切换伙伴或模型。

回复是流式的，能看到思考过程和工具调用，具体取决于模型和你的设置。

消息可以复制、重新生成、重发，也能 **从此处创建分支**，从某条消息岔出一条新的对话线。

另外还有快捷指令、会话级的网络搜索开关（全局那层也得在设置里启用搜索工具）、TTS 朗读（关闭 / 始终朗读 / 手动）、自定义聊天背景，以及附件收发。

## 身份卡

在设置里可以维护自己的昵称和头像，还能建多套身份卡，比如工作、旅行各一套，用键值条目描述你自己。

对话时注入身份卡，伙伴对你的称呼和背景认知会稳定很多。

## 伙伴「不记得」我写过什么

按顺序排查：

1. 日记写得够多吗？内容太少确实没什么可搜的。
2. 这是亲密伙伴吗？日记和记忆类工具启用了吗？
3. 嵌入模型和 RAG 正常吗？有没有提示未索引？见 [RAG 记忆管理](/docs/configure/rag/)。
4. 需不需要用唤醒回忆或共同回忆，直接注入一段较长时间的摘要？见 [回忆与共同回忆](/docs/basics/memories/)。
