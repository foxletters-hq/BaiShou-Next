日记是白守的记忆锚点。伙伴的理解、回忆总结、语义检索，全都建立在你持续写下的内容上。没有日记，后面那套记忆系统就是空的。

这一节讲日记是什么、和 AI 怎么衔接。从空白配到能聊天，见 [十分钟聊起来](/docs/getting-started/quick-start/)。

入口：桌面端在侧栏「日记」，移动端在底栏「日记」。

## 怎么写

1. 新建一篇日记，默认按当天日期。
2. 用 Markdown 写，两端都是即时预览的编辑体验。
3. 顺手补上天气、心情、标签、位置，也可以收藏。
4. 保存后按年月浏览，或者按收藏、天气、心情筛选。

其他常用操作：改日记日期、删除日记（会先确认）、离开时提示未保存、导出 Markdown、插入附件（图片放进 Markdown 里引用）。

## 用模板省事

在 **设置 → 日记格式** 里可以配三种模板：新建日记时的模板、追加记录时的模板、伙伴代写日记时要遵守的格式。

模板里能用 `{time}`、`{date}`、`{datetime}` 这些变量。

## 日记和 AI 的关系

亲密伙伴可以通过工具读写和搜索你的日记，前提是在工具管理里启用了对应工具。

日记保存后会自动尝试做向量嵌入。万一失败，去 RAG 页点一次 **全量扫描未索引日记** 补上，详见 [RAG 记忆管理](/docs/configure/rag/)。

日记也是生成周记到年鉴的原材料，逐层怎么读见 [回忆与共同回忆](/docs/basics/memories/)。

## 几个小建议

不用逼自己每天写长文，三两句也算。重要的事情加个标签或收藏，以后筛选和唤醒都好找。另外记得定期确认自己的备份策略，别等出事才想起来。
