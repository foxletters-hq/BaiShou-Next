白守是一款开源的、本地优先的 AI 记忆陪伴软件。

你在本地写下日记和生活片段，白守把它们逐层总结成「回忆年轮」，再交给 AI 伙伴长期理解、检索和陪伴。数据不进某个云端账号，留在你自己的设备上。

> 以纯白誓约，守护彼此一生。

## 它能做什么

| 能力 | 说明 |
|------|------|
| 日记与回忆年轮 | Markdown 书写，逐层凝结为周记、月报、季报、年鉴长程记忆 |
| 人生关系图谱 | 内置实体关系图数据库，自动化梳理人物关系网络与时间因果脉络 |
| 自主 AI Agent | 具备规划与工具调用能力，支持 MCP 开放协议无缝连接外部生态 |
| 专属 AI 伙伴 | 多伙伴人格定制与独立模型绑定，在长期共同记忆之上自然对话与陪伴 |
| 混合 Graph RAG | 全文检索、向量检索与图谱多跳推理相结合，深层穿透个人记忆 |
| 工作空间与多端同步 | 隔离的多工作区，支持端到端加密同步与自建 S3 / WebDAV 备份 |

:::tip[图数据库与 Agent 能力全面就绪]
白守现已全面引入嵌入式实体关系图数据库与自主 Agent 智能体系统，不仅能记录生活随笔，还能将日常对话与琐碎记忆编织成可交互、可推理的立体网络。
:::

## 和 Notion、Obsidian 有什么不一样

笔记工具解决的是「资料放得整齐」，白守想解决的是「AI 真的记得你」。

| | 笔记工具 | 白守 |
|--|----------|------|
| 重心 | 整理、双链、写作 | 被 AI 长期理解和使用的个人记忆 |
| AI | 多是插件或外挂的对话框 | 伙伴、回忆年轮、RAG 就是产品骨架 |
| 数据 | 常依赖官方云或插件生态 | 默认在本地，可选同步到你自建的 S3 / WebDAV |

## 我们坚持的几件事

1. **本地优先**：核心数据在你的设备上，随时能导出、能带走。
2. **核心能力开放**：日记、自建同步、自定义模型 API 不设付费墙。
3. **让 AI 读懂你的资料**：能检索、能问答、能总结，而不只是个网盘。
4. **官方服务只是选项**：想省事可以用，不付费同样能完整使用。
