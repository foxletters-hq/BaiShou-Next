---
title: 十分钟聊起来
description: 配置供应商、选择模型、开启 RAG，写下日记并和伙伴对话。
---

这篇只做一件事：从空白配置走到「问得动日记」。顺序是固定的——配密钥、选模型、确认 RAG、写一篇、再问伙伴。

截图来自桌面端中文界面。Android 菜单名相同，从底栏 **设置** 进去即可。

同步、TTS、联网搜索、MCP、自建伙伴、回忆年轮都不在这里。引导里的 API 可以跳过，配完再回来。

## 你需要准备什么

白守不托管密钥。最少要两类模型：一类用来聊天，一类用来把日记做成可检索的向量。

| 用途 | 推荐去哪 |
|------|----------|
| 对话、总结、会话命名 | [DeepSeek 开放平台](https://platform.deepseek.com/) |
| 嵌入（RAG） | [硅基流动](https://siliconflow.cn/) |

一家供应商同时提供对话和嵌入也可以，少配一家就行。下面按「DeepSeek + 硅基流动」走一遍，国内比较好申请。

## 1. 打开设置

侧栏底部点 **系统设置**。如果你已经把「供应商管理」钉到侧栏，也可以直接点进去。

![侧栏底部的系统设置](/assets/images/docs/quickstart/01.png)

*侧栏底部「系统设置」。新用户默认侧栏不一定能直接看到供应商入口，走设置最稳。*

## 2. 拿到对话用的 API Key

打开 [DeepSeek 开放平台](https://platform.deepseek.com/)，进入 **API keys**，点 **创建 API key**。完整密钥只在创建时显示一次，复制后回到白守粘贴。

![DeepSeek 开放平台的 API keys 页](/assets/images/docs/quickstart/04.png)

*在 DeepSeek 控制台创建密钥。不要把完整 Key 发到任何地方。*

## 3. 配置 DeepSeek

打开 **设置 → 供应商管理**，左侧点 **DeepSeek**。

1. 右上角开关打开。没开等于没用。
2. 把 Key 填进 API 配置。Base URL 一般不用改。
3. 点 **获取模型**，在列表里打开要用的对话模型。
4. 点 **测试连接**，弹窗里选对话模型，不要选 Embedding、Rerank 或 TTS。
5. 点底部 **保存修改**。这步最容易漏。

![供应商管理中的 DeepSeek](/assets/images/docs/quickstart/02.png)

![先获取模型，再测试连接](/assets/images/docs/quickstart/03.png)

*按图上的 1、2：先获取并勾选模型，再测连接。列表是空的话，测试会没有可选的对话模型。*

## 4. 拿到嵌入用的 API Key

打开 [硅基流动](https://siliconflow.cn/)，先完成实名认证，再到账户管理里的 **API 密钥** 创建 Key。

嵌入模型稍后在白守里勾选，不用在网页上单独「开通 RAG」。

![硅基流动控制台：先实名，再拿 API Key](/assets/images/docs/quickstart/05.png)

*先实名，再打开「API 密钥」。模型广场只是目录，真正启用发生在白守里。*

## 5. 配置硅基流动

回到 **供应商管理**，左侧点 **硅基流动**，同样走一遍：开开关 → 填 Key → **获取模型** → 只打开嵌入模型 → **保存修改**。

列表可能有几十上百个。用搜索框找名字里带 `embed` / `embedding` 的，例如 `Qwen/Qwen3-Embedding-8B`。聊天模型在这里不必打开。

![硅基流动已启用嵌入模型](/assets/images/docs/quickstart/06.png)

:::caution[聊天模型和嵌入模型不是一类]
只配 DeepSeek、不配嵌入，伙伴能聊，但搜不到日记细节。语义搜索依赖嵌入模型。
:::

## 6. 分配全局默认模型

打开 **设置 → 全局默认模型**。供应商里勾过的模型，这里才能选到。

| 卡片 | 必配？ | 选什么 |
|------|--------|--------|
| 默认对话模型 | 必配 | DeepSeek 的对话模型 |
| 嵌入模型 (Embedding) | 必配 | 硅基流动的嵌入模型 |
| 记忆总结模型 | 建议 | 可与对话同一家 |
| 默认命名模型 | 可后配 | 小模型即可，用来给会话起标题 |

点卡片上的选择器分配。嵌入那一张最容易漏，界面上也会特别标出来。

![四类全局默认模型都已分配](/assets/images/docs/quickstart/07.png)

TTS 在另一页，先不用管。换嵌入模型时如果弹出「更换嵌入模型？」，新用户没有旧向量，确认即可。已经有日记向量时不要随便换，详见 [RAG 记忆管理](/docs/configure/rag/)。

## 7. 确认 RAG 开着

打开 **设置 → RAG 记忆管理**。

- 标题旁的开关打开。默认就是开的；关掉会出现「RAG记忆功能已经关闭了喵~」。
- 标题下面那一行 **模型:** 应是你刚选的嵌入模型，不能是「未配置(点击跳转)」。
- 日记向量可以还是 0，下一步再写日记。
- **检索参数调节** 先别动。阈值调太高会搜不到。

![RAG 已开启，嵌入模型已显示](/assets/images/docs/quickstart/08.png)

## 8. 写一篇日记

关掉设置，点 **+ 写日记**。留下一件之后能问出来的事——吃了什么、去了哪里、今天心情怎么样都可以——然后保存。

保存后会自动尝试嵌入。失败的话，界面会提示你去 RAG 页补扫。

![日记列表里已经有内容](/assets/images/docs/quickstart/09.png)

## 9. 确认日记进了检索库

再打开 **RAG 记忆管理**。若 **日记向量** 还是 0，点 **全量扫描未索引日记**。扫完后，下方列表出现日记、**日记向量** 大于 0，这一步就完成了。

![RAG 中已出现日记向量](/assets/images/docs/quickstart/10.png)

也可以在搜索框里切到 **语义搜索**，用日记里的词试一下。搜得到就说明嵌入是通的。

## 10. 问 Latte

打开顶部 **伙伴**。默认伙伴是 **Latte**，类型为 **亲密伙伴**。新建对话，直接问日记里的事，例如「我最近吃了什么？」。

回复里如果展开看到 **日记搜索**、**语义搜索**，说明记忆检索已经在工作。

![向 Latte 提问并检索到日记](/assets/images/docs/quickstart/11.png)

:::tip[必须是亲密伙伴]
工作伙伴默认不能读写日记，也用不了语义搜索。这是设计如此。伙伴类型见 [AI 伙伴与对话](/docs/basics/companions/)。
:::

对话模型需要支持工具调用。刚写入的向量偶尔有几秒延迟，搜不到就再问一次，或回 RAG 页看向量数。

## 最容易漏的几步

1. 供应商右上角开关没开。
2. 获取模型后没有勾选。
3. 没点 **保存修改**。
4. 全局默认模型只配了聊天，没配 **嵌入模型**。
5. RAG 标题旁的开关被关掉。
6. 还没写日记就问「你记得我吗」。
7. 用工作伙伴去问日记。
