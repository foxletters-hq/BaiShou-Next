第一次打开白守会走一遍引导，大约七步。之后都能在设置里改，但语言和存储位置建议一开始就选好。

## 引导会问你什么

| 步骤 | 你在做什么 |
|------|------------|
| 选择语言 | 界面语言。默认伙伴 Latte 也会按这个语言创建 |
| 欢迎 | 认识一下白守 |
| 书写我们的回忆 | 说明日记是整套记忆的锚点 |
| 复制共同回忆 | 了解周记、月报、季报、年鉴是怎么来的 |
| 选择存储位置 | 数据存在哪里 |
| API / 供应商 | 模型密钥由你自备，可以跳过 |
| 保护您的隐私 | 本地处理的说明 |

走完进主界面，此时已经有一个看板娘伙伴 Latte。

## 存储位置怎么选

桌面端选一个你记得住、方便备份的文件夹当存储根目录就行。

Android 默认存在应用沙盒里。想和桌面的目录结构对齐，可以启用外部的 `BaiShou_Root`，这通常需要更高的存储权限。

两者的区别和风险详见 [工作区与数据位置](/docs/configure/workspace/)。

## API 可以稍后再配吗

可以，引导里直接跳过。之后按 [十分钟聊起来](/docs/getting-started/quick-start/) 配供应商、选模型、打开 RAG，就能开始对话。

不过要知道会缺什么：没有对话模型，伙伴聊不了；没有嵌入模型，日记的自动嵌入和语义搜索会不正常。完整对照见 [配置 AI 供应商与模型](/docs/configure/ai-providers/)。

## 从旧版升级上来的

如果你是从旧版 Flutter 白守覆盖安装的，启动后可能会看到 **版本迁移** 提示。请按 [从旧版白守迁移](/docs/migrate/from-legacy/) 一步步来，先别急着删旧的数据目录。
