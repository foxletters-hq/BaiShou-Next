## 工作空间

你可以建多个工作空间，彼此数据隔离，适合把生活、项目、测试分开放。常用操作就是创建、切换、删除，删之前请确认已经备份过。

会随工作区切换的，主要是日记、回忆总结、伙伴与聊天、附件这些业务数据。

偏全局、不跟着切的，一般是主题与语言、部分 AI 与 RAG 配置、昵称与身份卡，以及工作区列表和存储根位置本身。

具体边界以你当前版本的设置为准。不确定的话，先做一次 [本地全量备份](/docs/sync/backup/) 再动手。

## 存储根目录

桌面端在首次引导或 **存储管理** 里选数据目录。挑一个你有写权限、空间够、也方便备份的位置。

Android 有两种：

- 默认存在应用沙盒里。卸载应用可能一起没了，所以要定期备份。
- 也可以启用外部的 `BaiShou_Root`，目录结构和桌面对齐，但通常需要「所有文件访问」这类权限。各家厂商的设置入口名字都不一样。

:::caution
权限按最小必要给。公共电脑或者共用设备上更要谨慎。
:::

## 数据是怎么存的

白守倾向用本地可读、可控的方式保存内容，比如 Markdown 加 SQLite。不过还是建议你保留导出和备份的习惯，别把「云会一直替我保管」当默认前提。
