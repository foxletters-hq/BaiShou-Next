## 配置顺序

1. 打开 **设置 → 供应商管理**，添加供应商。OpenAI、Gemini、DeepSeek、Anthropic 以及各种 OpenAI 兼容接口都可以。
2. 填 API Key，需要的话填 Base URL，勾选你要用的模型，可以先测一下连通性。
3. 打开 **设置 → 全局默认模型**，分别指定下面这几类。

不知道 Key 从哪拿、或者整套流程怎么配？可以直接去官网申请，也可以对着视频做：

| 你要什么 | 去哪 |
|----------|------|
| 对话 / 总结用的 DeepSeek API | [DeepSeek 开放平台](https://platform.deepseek.com/) |
| 嵌入模型 | [硅基流动 SiliconFlow](https://siliconflow.cn/) |
| 从头跟着配一遍 | [Bilibili 配置演示](https://www.bilibili.com/video/BV1FRuTzwEig) |

## 四类默认模型分别管什么

这一步最容易漏，很多「为什么 XX 不能用」都出在这。

| 类型 | 用在哪 | 不配的后果 |
|------|--------|------------|
| 对话模型 | 伙伴聊天 | 聊不了 |
| 记忆总结模型 | 生成周记到年鉴 | 回忆生成失败 |
| 嵌入模型 | 日记与记忆向量化、RAG 检索 | 自动嵌入和语义搜索不正常 |
| TTS 模型 | 语音朗读 | 只影响朗读功能 |

伙伴也可以单独绑定专用模型，没绑的就走全局对话模型。

## 供应商侧还有什么

除了启用哪些模型和排序，每个模型还有一个 **网络搜索模式**，只有两个值：关闭，或者走外部工具（默认）。

也就是说白守的联网搜索统一由自己的搜索工具完成，不依赖模型自带的搜索能力。具体引擎怎么选见 [网络搜索与工具](/docs/advanced/tools-search/)。

## 安全提示

Key 存在本机。开了增量同步之后，云端目标里可能出现含密钥的设置文件，所以请限制云存储权限，也别在不可信环境同步。

对话、总结、嵌入请求都直接发往你配置的模型服务商，不经过白守的服务器。

## 常见故障对照

| 现象 | 一般是什么原因 |
|------|----------------|
| 一直转圈或直接报错 | Key、Base URL、模型名写错，或者账户欠费、网络不通 |
| 能聊天但生成不了回忆 | 没配记忆总结模型 |
| 伙伴搜不到日记 | 没配嵌入模型，或者 RAG 还没索引，见 [RAG 记忆管理](/docs/configure/rag/) |
| 换了嵌入模型后检索全乱 | 需要做向量库迁移，见 [RAG 记忆管理](/docs/configure/rag/) |
