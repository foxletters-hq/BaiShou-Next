下面这些能力只在桌面端（Electron）有，移动端没有或者形态不同。完整对照见 [桌面与移动差异](/docs/reference/platforms/)。

## 全局快捷键

可以在设置里配全局快捷键，比如默认用 Alt+S 显示和隐藏窗口。在别的应用里也能触发，适合想到什么随手记一句。

## 侧边栏管理

自定义侧栏项的显示、隐藏和排序。默认可见的一般包括日记、回忆、增量同步、版本控制这些。

## Git 版本控制

桌面端可以对存储根目录做 Git 操作：初始化、提交、推送拉取、配置远程和 Token，以及处理冲突。

适合把桌面当主库、需要历史版本和误操作回滚的人，和 [增量同步](/docs/sync/incremental/) 搭配用效果最好。

:::tip[三个概念别混]
Git 版本控制不是增量同步，也不是 ZIP 全量备份。三者的分工见 [三种方式怎么选](/docs/sync/overview/)。
:::

## 本地搜索引擎

桌面端能借 Electron 的隐藏窗口去抓 Bing 和 Google 的结果页，所以网络搜索里多了 **Bing 本地搜索** 和 **Google 本地搜索** 两个不需要 API Key 的选项。移动端没有。见 [网络搜索与工具](/docs/advanced/tools-search/)。

## 其他

设置既能从侧栏进，也能开全屏设置页，具体 UI 随版本会调整。

**关于白守** 里有版本信息、反馈入口和诊断日志导出。提 Issue 的时候带上诊断日志会快很多。
