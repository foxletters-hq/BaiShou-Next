伙伴除了聊天，还能调用工具去读写日记、检索记忆、上网搜索。这一页讲清有哪些工具、开关藏在哪几层、搜索引擎怎么选。

## 内置工具清单

入口在 **设置 → 工具管理**，按分类列出。

| 分类 | 工具 | 做什么 |
|------|------|--------|
| 日记 | 日记读取 | 按日期读全文，一次最多 20 篇 |
| 日记 | 日记写入 | 在指定日期新建日记 |
| 日记 | 日记编辑 | 追加或整篇覆盖，默认是追加 |
| 日记 | 日记删除 | 删掉指定日期的日记，不可恢复 |
| 日记 | 日记列表 | 列出某段时间内有日记的日子 |
| 日记 | 日记搜索 | 本地全文关键词搜索 |
| 总结 | 总结读取 | 读周记、月报、季报、年鉴 |
| 记忆 | 消息搜索 | 跨会话搜历史聊天记录 |
| 记忆 | 语义搜索 | 向量或混合检索，找相关片段 |
| 记忆 | 记忆存储 | 把内容写入长期向量记忆 |
| 记忆 | 记忆删除 | 语义匹配后删除记忆 |
| 搜索 | 网络搜索 | 联网搜索，一次可发 1 到 3 条查询 |
| 搜索 | 网页读取 | 抓取指定网址的正文 |
| 通用 | 查询时间 | 拿到当前真实时间，这个不能关 |

工具管理页还有一项 **当前时间**，它不是工具，只控制要不要在系统提示词里自动带上当前时间，默认关闭。

另外表情包发送算伙伴能力而不是工具，在表情包设置里管。

## 开关分四层

「为什么我的伙伴不会用某个工具」基本都出在这四层的某一层，从上往下查：

1. **工具管理（全局）**：在这里关掉的工具，任何伙伴都用不了。
2. **伙伴类型**：工作伙伴会自动禁用所有日记、总结、记忆、语义搜索类工具，只留网络搜索、网页读取、时间这些。这是设计如此，不是 bug，详见 [AI 伙伴与对话](/docs/basics/companions/)。
3. **RAG 开关与嵌入模型**：关了 RAG 或者没配嵌入模型，语义搜索和记忆存储直接不可用。
4. **会话级联网开关**：对话输入栏那个搜索按钮。它没开的话，网络搜索工具不会给到模型，伙伴会回你「您还未启用网络搜索，请在工具栏开启后重试」。

第 4 层最容易被忽略，因为它和工具管理里的网络搜索是两个独立开关，两个都得开。

## 搜索引擎怎么选

在网络搜索设置里选引擎，默认是 Exa MCP，不需要任何 Key 就能用。

| 引擎 | 要 API Key | 说明 |
|------|------------|------|
| Exa MCP | 不要 | 默认选项，开箱可用 |
| DuckDuckGo | 不要 | 抓取 HTML 结果页，偶尔会被限流 |
| Tavily API | 要 | 面向 AI 的搜索 API |
| Exa API | 要 | Exa 官方 API，比 MCP 那条路可控 |
| AnySearch API | 要 | 国内环境，默认中文区域 |
| Bing 本地搜索 | 不要 | 用本地浏览器抓 Bing 结果页，仅桌面端 |
| Google 本地搜索 | 不要 | 同上，仅桌面端 |

移动端没有那两个本地搜索选项，只有前五个。

主引擎失败时，白守会自动降级到其他已配好 Key 的引擎重试。但两个本地搜索失败后不会降级，会直接报错。

## 搜索的可调参数

| 参数 | 默认 | 说明 |
|------|------|------|
| 最大结果数 | 5 | 每条查询返回多少结果，上限 30 |
| 网页 RAG 压缩 | 关闭 | 开启后对抓到的网页做切块压缩，只留相关部分 |
| RAG 总片段上限 | 12 | 开启压缩后，一次最多保留多少片段 |
| 单站片段上限 | 4 | 防止某一个网站占满全部额度 |
| 纯文本截取长度 | 3000 | 不用 RAG 压缩时，每个网页截多少字符 |

结果太少就加大最大结果数；上下文被网页内容挤爆了就开 RAG 压缩，或者调小截取长度。

:::note[搜索会把内容发出去]
搜索请求会发往你选的搜索服务，网页正文还会进到模型的上下文里。这意味着额外的费用和隐私暴露面，按需开启。
:::

## TTS 与表情包

**TTS 语音合成** 可以配 OpenAI 兼容接口、小米 MiMo、MiniMax、本地 GPT-SoVITS 等。配好之后在对话里选关闭、始终朗读或手动朗读。

**表情包设置** 里管理表情包组，再按伙伴决定启用哪几组。

## 常见失败

| 现象 | 原因 |
|------|------|
| 伙伴说「您还未启用网络搜索」 | 会话工具栏的搜索开关没开 |
| 搜索报 API key is missing or invalid | 选了要 Key 的引擎但没填，或者填错了 |
| 提示嵌入模型未配置，无法存储记忆 | 去全局默认模型里配嵌入模型，见 [配置 AI 供应商与模型](/docs/configure/ai-providers/) |
| 提示日记索引未就绪 | 去 RAG 页做一次全量扫描，见 [RAG 记忆管理](/docs/configure/rag/) |
| 伙伴完全不调用工具 | 大概率模型本身不支持 function calling，换一个支持工具调用的模型 |
| 网页读取说内容不可访问 | 目标站点反爬或需要登录，换个来源 |
