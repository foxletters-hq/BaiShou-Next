## 本地优先是什么意思

日记和核心业务数据默认就存在你的设备上。

除了你自己配置的模型 API 和同步备份远端，白守不会把日记上传到「白守自有服务器」来完成基本功能。

## 什么情况下数据会出网

| 你做了什么 | 数据去哪 |
|------------|----------|
| 和 AI 对话、生成总结、做嵌入 | 你配置的模型服务商 |
| 网络搜索 | 你选的搜索引擎服务，抓到的网页正文还会进模型上下文 |
| 增量同步、云端备份 | 你配置的 S3 / WebDAV |

这些都由你主动配置触发。建议顺手读一下对应服务商的隐私政策，同步范围也按需最小化。

## 收费怎么算

核心能力免费开源：日记、自建同步、自定义模型 API 都不设付费墙。

如果之后提供官方服务（加密同步、托管备份、官方 AI 之类），那是可选项，按官网说明购买。不付费同样能完整使用，数据也随时能带走。

## 开源许可

项目开源发布，许可以仓库里的 `LICENSE` 为准（当前为 AGPLv3）。欢迎通过 Issue 或 PR 反馈问题，文档改进也一样欢迎。
