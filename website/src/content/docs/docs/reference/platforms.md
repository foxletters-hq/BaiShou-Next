---
title: 桌面与移动差异
description: Windows 桌面端与 Android 移动端在导航、功能与存储上的差异。
---

两端共享日记、回忆、伙伴、RAG、同步这些核心能力。差别主要在外壳和几个高级功能上。

## 对照

| 维度 | 桌面（Windows） | 移动（Android） |
|------|------|-----------------|
| 导航 | 可定制侧栏 | 底栏：日记 / 伙伴 / 回忆 / 设置 |
| Git 版本控制 | 有 | 无 |
| MCP 服务 | 有，另带旧版 `/sse` 兼容端点 | Android 也有，只支持 `/mcp` |
| 全局快捷键 | 有 | 无 |
| 搜索引擎选项 | 7 种，含 Bing / Google 本地搜索 | 5 种，没有本地搜索 |
| 存储位置 | 自选目录 | 应用沙盒，或外部 `BaiShou_Root` |
| 官方安装包 | Windows 安装器 | APK |

## 建议怎么搭

主力写作、需要 Git 兜底的话用桌面端。

碎片记录和随时翻看用手机。

同步方式的选择见 [三种方式怎么选](/docs/sync/overview/)。移动端更适合当单向备份，或者双向时格外小心。
