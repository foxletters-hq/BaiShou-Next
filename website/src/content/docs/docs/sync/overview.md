白守里有好几套「把数据挪到别处」的能力，名字看着都像同步，用途其实差挺远。把云路径混在一起、或者搞错覆盖范围，是最常见的翻车原因。

## 四种能力对照

| 方式 | 做什么 | 什么时候用 | 要注意 |
|------|--------|------------|--------|
| 增量同步 | 按文件做增量对齐，覆盖日记、总结、会话、伙伴、附件和部分设置 | 多台设备持续同步到自建 S3 / WebDAV | 云路径和全量备份不同，且可能包含含密钥的设置 |
| 数据备份 | ZIP 全量导出导入，或者往云端放全量包 | 换机、灾备、阶段性存档 | 路径和范围都和增量不同，别当同一套用 |
| 局域网传输 | 同一个 Wi-Fi 下整库互传 | 桌面和手机之间快速搬家 | 需要同网络，注意别搞反方向 |
| 版本控制 | 桌面端对存储根做 Git 提交和推送 | 想要历史版本和回滚 | 仅桌面端，可以和增量同步互补 |

## 按需求选

只想留条后路，就用本地 ZIP 全量备份，定期拷到别的地方。

两台设备日常要对齐，用增量同步到你自己的 S3 或 WebDAV，桌面端建议再开 Git 兜底。

偶尔换机重装，走全量备份导入，或者局域网直接传。

移动端建议当单向备份用，或者双向时格外小心。手机的权限和后台限制比桌面多。

## 一个安全提醒

增量同步的范围可能包含 `.baishou/settings/` 这类配置目录，里面可能有 API Key。所以：

- 用私有桶或私有 WebDAV，权限给到最小
- 别把同步目标设成公开可读的地址
- 共用电脑上先想清楚风险再同步
