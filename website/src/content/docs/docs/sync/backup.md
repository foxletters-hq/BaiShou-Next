需要「整包带走」或者「出事能回滚」的时候，用备份，别用增量同步。

## 有哪几种

| 能力 | 说明 |
|------|------|
| 本地 ZIP 备份 | 导出和导入完整备份包 |
| 云端备份 | 把全量包放到 S3 或 WebDAV，路径和增量同步分开 |
| 本地快照 | 重大操作前自动保护，触发条件随版本 |
| 局域网传输 | 同一 Wi-Fi 下设备间整库互传 |

## 导出的习惯

定期做本地 ZIP，并且复制到第二个地方，比如移动硬盘或另一个云盘。只放一份不叫备份。

大版本升级或迁移之前，先备份一次。

导入前确认目标设备空间够，并且把覆盖提示看完。

## 导入要留意

导入可能覆盖现有数据，提示别一路点确定。

从旧版上来优先走 [版本迁移](/docs/migrate/from-legacy/)，不要指望随手解压一个目录就完事。

导入完如果伙伴突然「失忆」，去 RAG 页做一次 [全量扫描](/docs/configure/rag/)，通常是向量库没跟上。

## 附件

**附件管理** 里能看日记附件和会话附件，也能清理孤立文件。清理前确认没有还在被引用的内容。
