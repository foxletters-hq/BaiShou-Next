旧版 Flutter 客户端已经停止维护，现行产品是 BaiShou-Next（桌面 Electron 加移动 Expo）。

## 移动端怎么升

Android 如果包名相同，直接装新 APK 覆盖就行。但要清楚：覆盖安装不等于数据自动迁移好了，还得用应用内的 **版本迁移** 走一遍。

## 版本迁移的三条原则

按板块选择性导入，而不是一次全灌。

不要删旧数据目录，出问题还能回去看。

按顺序来，尤其聊天记录要排在伙伴之后，不然映射容易错：

1. 全局数据：头像、身份卡、配置
2. 各工作空间的日记
3. 伙伴
4. 聊天记录

## 迁完还要做几件事

1. 有提示就重启一次应用。
2. 检查日记和伙伴是否齐全。
3. 确认 [AI 供应商与模型](/docs/configure/ai-providers/) 配好了。
4. 去 RAG 页执行 **全量扫描未索引日记**。继承来的日记通常需要重建向量库，详见 [RAG 记忆管理](/docs/configure/rag/)。
5. 做一份 [本地全量备份](/docs/sync/backup/)。

## 别做这些

迁移彻底完成前不要删旧目录，也别清空存储。

不要以为「能聊天了」就等于 RAG 已经就绪，这是两回事。

反馈问题请到 BaiShou-Next 仓库，旧仓库的 Issues 已经不看了。
