## 設定順序

1. 打開 **設定 → 供應商管理**，新增供應商。OpenAI、Gemini、DeepSeek、Anthropic 以及各種 OpenAI 相容介面都可以。
2. 填 API Key，需要的話填 Base URL，勾選你要用的模型，可以先測一下連線。
3. 打開 **設定 → 全域預設模型**，分別指定下面這幾類。

不知道 Key 從哪拿、或者整套流程怎麼配？可以直接去官網申請，也可以對著影片做：

| 你要什麼 | 去哪 |
|----------|------|
| 對話 / 總結用的 DeepSeek API | [DeepSeek 開放平台](https://platform.deepseek.com/) |
| 嵌入模型 | [矽基流動 SiliconFlow](https://siliconflow.cn/) |
| 從頭跟著配一遍 | [Bilibili 設定演示](https://www.bilibili.com/video/BV1FRuTzwEig) |

## 四類預設模型分別管什麼

這一步最容易漏，很多「為什麼 XX 不能用」都出在這。

| 類型 | 用在哪 | 不設定的後果 |
|------|--------|------------|
| 對話模型 | 夥伴聊天 | 聊不了 |
| 記憶總結模型 | 生成週記到年鑑 | 回憶生成失敗 |
| 嵌入模型 | 日記與記憶向量化、RAG 檢索 | 自動嵌入和語意搜尋不正常 |
| TTS 模型 | 語音朗讀 | 只影響朗讀功能 |

夥伴也可以單獨綁定專用模型，沒綁的就走全域對話模型。

## 供應商側還有什麼

除了啟用哪些模型和排序，每個模型還有一個 **網路搜尋模式**，只有兩個值：關閉，或者走外部工具（預設）。

也就是說白守的連網搜尋統一由自己的搜尋工具完成，不依賴模型自帶的搜尋能力。具體引擎怎麼選見 [網路搜尋與工具](/zh-tw/docs/advanced/tools-search/)。

## 安全提示

Key 存在本機。開了增量同步之後，雲端目標裡可能出現含金鑰的設定檔，所以請限制雲端儲存權限，也別在不可信環境同步。

對話、總結、嵌入請求都直接發往你設定的模型服務商，不經過白守的伺服器。

## 常見故障對照

| 現象 | 一般是什麼原因 |
|------|----------------|
| 一直轉圈或直接報錯 | Key、Base URL、模型名寫錯，或者帳戶欠費、網路不通 |
| 能聊天但生成不了回憶 | 沒設定記憶總結模型 |
| 夥伴搜不到日記 | 沒設定嵌入模型，或者 RAG 還沒索引，見 [RAG 記憶管理](/zh-tw/docs/configure/rag/) |
| 換了嵌入模型後檢索全亂 | 需要做向量庫遷移，見 [RAG 記憶管理](/zh-tw/docs/configure/rag/) |
