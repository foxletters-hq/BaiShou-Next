## 工作空間

你可以建多個工作空間，彼此資料隔離，適合把生活、專案、測試分開放。常用操作就是建立、切換、刪除，刪之前請確認已經備份過。

會隨工作區切換的，主要是日記、回憶總結、夥伴與聊天、附件這些業務資料。

偏全域、不跟著切的，一般是主題與語言、部分 AI 與 RAG 設定、暱稱與身分卡，以及工作區列表和儲存根位置本身。

具體邊界以你目前版本的設定為準。不確定的話，先做一次 [本地全量備份](/zh-tw/docs/sync/backup/) 再動手。

## 儲存根目錄

桌面端在首次引導或 **儲存管理** 裡選資料目錄。挑一個你有寫入權限、空間夠、也方便備份的位置。

Android 有兩種：

- 預設存在應用程式沙盒裡。解除安裝應用程式可能一起沒了，所以要定期備份。
- 也可以啟用外部的 `BaiShou_Root`，目錄結構和桌面對齊，但通常需要「所有檔案存取」這類權限。各家廠商的設定入口名字都不一樣。

:::caution
權限按最小必要給。公用電腦或者共用裝置上更要謹慎。
:::

## 資料是怎麼存的

白守傾向用本地可讀、可控的方式保存內容，比如 Markdown 加 SQLite。不過還是建議你保留匯出和備份的習慣，別把「雲端會一直替我保管」當預設前提。
