title: 桌面與行動差異
description: Windows 桌面端與 Android 行動端在導覽、功能與儲存上的差異。
---

兩端共享日記、回憶、夥伴、RAG、同步這些核心能力。差別主要在外殼和幾個進階功能上。

## 對照

| 維度 | 桌面（Windows） | 行動（Android） |
|------|------|-----------------|
| 導覽 | 可自訂側欄 | 底欄：日記 / 夥伴 / 回憶 / 設定 |
| Git 版本控制 | 有 | 無 |
| MCP 服務 | 有，另帶舊版 `/sse` 相容端點 | Android 也有，只支援 `/mcp` |
| 全域快捷鍵 | 有 | 無 |
| 搜尋引擎選項 | 7 種，含 Bing / Google 本地搜尋 | 5 種，沒有本地搜尋 |
| 儲存位置 | 自選目錄 | 應用程式沙盒，或外部 `BaiShou_Root` |
| 官方安裝包 | Windows 安裝器 | APK |

## 建議怎麼搭

主力寫作、需要 Git 兜底的話用桌面端。

碎片記錄和隨時翻看用手機。

同步方式的選擇見 [三種方式怎麼選](/zh-tw/docs/sync/overview/)。行動端更適合當單向備份，或者雙向時格外小心。
