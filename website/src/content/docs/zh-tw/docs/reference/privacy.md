## 本地優先是什麼意思

日記和核心業務資料預設就存在你的裝置上。

除了你自己設定的模型 API 和同步備份遠端，白守不會把日記上傳到「白守自有伺服器」來完成基本功能。

## 什麼情況下資料會出網

| 你做了什麼 | 資料去哪 |
|------------|----------|
| 和 AI 對話、生成總結、做嵌入 | 你設定的模型服務商 |
| 網路搜尋 | 你選的搜尋引擎服務，抓到的網頁正文還會進模型上下文 |
| 增量同步、雲端備份 | 你設定的 S3 / WebDAV |

這些都由你主動設定觸發。建議順手讀一下對應服務商的隱私政策，同步範圍也按需最小化。

## 收費怎麼算

核心能力免費開源：日記、自建同步、自訂模型 API 都不設付費牆。

如果之後提供官方服務（加密同步、託管備份、官方 AI 之類），那是可選項，按官網說明購買。不付費同樣能完整使用，資料也隨時能帶走。

## 開源授權

專案開源發布，授權以倉庫裡的 `LICENSE` 為準（目前為 AGPLv3）。歡迎透過 Issue 或 PR 回饋問題，文件改進也一樣歡迎。
