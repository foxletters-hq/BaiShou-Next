---

舊版 Flutter 用戶端已經停止維護，現行產品是 BaiShou-Next（桌面 Electron 加行動 Expo）。

## 行動端怎麼升

Android 如果套件名稱相同，直接裝新 APK 覆蓋就行。但要清楚：覆蓋安裝不等於資料自動遷移好了，還得用應用程式內的 **版本遷移** 走一遍。

## 版本遷移的三條原則

按板塊選擇性匯入，而不是一次全灌。

不要刪舊資料目錄，出問題還能回去看。

按順序來，尤其聊天記錄要排在夥伴之後，不然對應容易錯：

1. 全域資料：頭像、身分卡、設定
2. 各工作空間的日記
3. 夥伴
4. 聊天記錄

## 遷完還要做幾件事

1. 有提示就重新啟動一次應用程式。
2. 檢查日記和夥伴是否齊全。
3. 確認 [AI 供應商與模型](/zh-tw/docs/configure/ai-providers/) 設定好了。
4. 去 RAG 頁執行 **全量掃描未索引日記**。繼承來的日記通常需要重建向量庫，詳見 [RAG 記憶管理](/zh-tw/docs/configure/rag/)。
5. 做一份 [本地全量備份](/zh-tw/docs/sync/backup/)。

## 別做這些

遷移徹底完成前不要刪舊目錄，也別清空儲存。

不要以為「能聊天了」就等於 RAG 已經就緒，這是兩回事。

回饋問題請到 BaiShou-Next 倉庫，舊倉庫的 Issues 已經不看了。
