下面這些能力只在桌面端（Electron）有，行動端沒有或者形態不同。完整對照見 [桌面與行動差異](/zh-tw/docs/reference/platforms/)。

## 全域快捷鍵

可以在設定裡設定全域快捷鍵，比如預設用 Alt+S 顯示和隱藏視窗。在別的應用程式裡也能觸發，適合想到什麼隨手記一句。

## 側邊欄管理

自訂側欄項的顯示、隱藏和排序。預設可見的一般包括日記、回憶、增量同步、版本控制這些。

## Git 版本控制

桌面端可以對儲存根目錄做 Git 操作：初始化、提交、推送拉取、設定遠端和 Token，以及處理衝突。

適合把桌面當主庫、需要歷史版本和誤操作回滾的人，和 [增量同步](/zh-tw/docs/sync/incremental/) 搭配用效果最好。

:::tip[三個概念別混]
Git 版本控制不是增量同步，也不是 ZIP 全量備份。三者的分工見 [三種方式怎麼選](/zh-tw/docs/sync/overview/)。
:::

## 本地搜尋引擎

桌面端能借 Electron 的隱藏視窗去抓 Bing 和 Google 的結果頁，所以網路搜尋裡多了 **Bing 本地搜尋** 和 **Google 本地搜尋** 兩個不需要 API Key 的選項。行動端沒有。見 [網路搜尋與工具](/zh-tw/docs/advanced/tools-search/)。

## 其他

設定既能從側欄進，也能開全螢幕設定頁，具體 UI 隨版本會調整。

**關於白守** 裡有版本資訊、回饋入口和診斷日誌匯出。提 Issue 的時候帶上診斷日誌會快很多。
