夥伴除了聊天，還能呼叫工具去讀寫日記、檢索記憶、上網搜尋。這一頁講清有哪些工具、開關藏在哪幾層、搜尋引擎怎麼選。

## 內建工具清單

入口在 **設定 → 工具管理**，按分類列出。

| 分類 | 工具 | 做什麼 |
|------|------|--------|
| 日記 | 日記讀取 | 按日期讀全文，一次最多 20 篇 |
| 日記 | 日記寫入 | 在指定日期新建日記 |
| 日記 | 日記編輯 | 追加或整篇覆蓋，預設是追加 |
| 日記 | 日記刪除 | 刪掉指定日期的日記，不可復原 |
| 日記 | 日記列表 | 列出某段時間內有日記的日子 |
| 日記 | 日記搜尋 | 本地全文關鍵字搜尋 |
| 總結 | 總結讀取 | 讀週記、月報、季報、年鑑 |
| 記憶 | 訊息搜尋 | 跨會話搜歷史聊天記錄 |
| 記憶 | 語意搜尋 | 向量或混合檢索，找相關片段 |
| 記憶 | 記憶儲存 | 把內容寫入長期向量記憶 |
| 記憶 | 記憶刪除 | 語意比對後刪除記憶 |
| 搜尋 | 網路搜尋 | 連網搜尋，一次可發 1 到 3 條查詢 |
| 搜尋 | 網頁讀取 | 抓取指定網址的正文 |
| 通用 | 查詢時間 | 拿到目前真實時間，這個不能關 |

工具管理頁還有一項 **目前時間**，它不是工具，只控制要不要在系統提示詞裡自動帶上目前時間，預設關閉。

另外表情包傳送算夥伴能力而不是工具，在表情包設定裡管。

## 開關分四層

「為什麼我的夥伴不會用某個工具」基本都出在這四層的某一層，從上往下查：

1. **工具管理（全域）**：在這裡關掉的工具，任何夥伴都用不了。
2. **夥伴類型**：工作夥伴會自動停用所有日記、總結、記憶、語意搜尋類工具，只留網路搜尋、網頁讀取、時間這些。這是設計如此，不是 bug，詳見 [AI 夥伴與對話](/zh-tw/docs/basics/companions/)。
3. **RAG 開關與嵌入模型**：關了 RAG 或者沒設定嵌入模型，語意搜尋和記憶儲存直接不可用。
4. **會話級連網開關**：對話輸入欄那個搜尋按鈕。它沒開的話，網路搜尋工具不會給到模型，夥伴會回你「您還未啟用網路搜尋，請在工具列開啟後重試」。

第 4 層最容易被忽略，因為它和工具管理裡的網路搜尋是兩個獨立開關，兩個都得開。

## 搜尋引擎怎麼選

在網路搜尋設定裡選引擎，預設是 Exa MCP，不需要任何 Key 就能用。

| 引擎 | 要 API Key | 說明 |
|------|------------|------|
| Exa MCP | 不要 | 預設選項，開箱可用 |
| DuckDuckGo | 不要 | 抓取 HTML 結果頁，偶爾會被限流 |
| Tavily API | 要 | 面向 AI 的搜尋 API |
| Exa API | 要 | Exa 官方 API，比 MCP 那條路可控 |
| AnySearch API | 要 | 中國大陸環境，預設中文區域 |
| Bing 本地搜尋 | 不要 | 用本地瀏覽器抓 Bing 結果頁，僅桌面端 |
| Google 本地搜尋 | 不要 | 同上，僅桌面端 |

行動端沒有那兩個本地搜尋選項，只有前五個。

主引擎失敗時，白守會自動降級到其他已設定好 Key 的引擎重試。但兩個本地搜尋失敗後不會降級，會直接報錯。

## 搜尋的可調參數

| 參數 | 預設 | 說明 |
|------|------|------|
| 最大結果數 | 5 | 每條查詢返回多少結果，上限 30 |
| 網頁 RAG 壓縮 | 關閉 | 開啟後對抓到的網頁做切塊壓縮，只留相關部分 |
| RAG 總片段上限 | 12 | 開啟壓縮後，一次最多保留多少片段 |
| 單站片段上限 | 4 | 防止某一個網站占滿全部額度 |
| 純文字擷取長度 | 3000 | 不用 RAG 壓縮時，每個網頁擷取多少字元 |

結果太少就加大最大結果數；上下文被網頁內容擠爆了就開 RAG 壓縮，或者調小擷取長度。

:::note[搜尋會把內容發出去]
搜尋請求會發往你選的搜尋服務，網頁正文還會進到模型的上下文裡。這意味著額外的費用和隱私暴露面，按需開啟。
:::

## TTS 與表情包

**TTS 語音合成** 可以設定 OpenAI 相容介面、小米 MiMo、MiniMax、本地 GPT-SoVITS 等。設定好之後在對話裡選關閉、始終朗讀或手動朗讀。

**表情包設定** 裡管理表情包組，再按夥伴決定啟用哪幾組。

## 常見失敗

| 現象 | 原因 |
|------|------|
| 夥伴說「您還未啟用網路搜尋」 | 會話工具列的搜尋開關沒開 |
| 搜尋報 API key is missing or invalid | 選了要 Key 的引擎但沒填，或者填錯了 |
| 提示嵌入模型未設定，無法儲存記憶 | 去全域預設模型裡設定嵌入模型，見 [設定 AI 供應商與模型](/zh-tw/docs/configure/ai-providers/) |
| 提示日記索引未就緒 | 去 RAG 頁做一次全量掃描，見 [RAG 記憶管理](/zh-tw/docs/configure/rag/) |
| 夥伴完全不呼叫工具 | 大概率模型本身不支援 function calling，換一個支援工具呼叫的模型 |
| 網頁讀取說內容不可存取 | 目標站點反爬或需要登入，換個來源 |
