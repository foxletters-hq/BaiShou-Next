日記是白守的記憶錨點。夥伴的理解、回憶總結、語意檢索，全都建立在你持續寫下的內容上。沒有日記，後面那套記憶系統就是空的。

這一節講日記是什麼、和 AI 怎麼銜接。從空白設定到能聊天，見 [十分鐘聊起來](/zh-tw/docs/getting-started/quick-start/)。

入口：桌面端在側欄「日記」，行動端在底欄「日記」。

## 怎麼寫

1. 新建一篇日記，預設按當天日期。
2. 用 Markdown 寫，兩端都是即時預覽的編輯體驗。
3. 順手補上天氣、心情、標籤、位置，也可以收藏。
4. 儲存後按年月瀏覽，或者按收藏、天氣、心情篩選。

其他常用操作：改日記日期、刪除日記（會先確認）、離開時提示未儲存、匯出 Markdown、插入附件（圖片放進 Markdown 裡引用）。

## 用範本省事

在 **設定 → 日記格式** 裡可以設定三種範本：新建日記時的範本、追加記錄時的範本、夥伴代寫日記時要遵守的格式。

範本裡能用 `{time}`、`{date}`、`{datetime}` 這些變數。

## 日記和 AI 的關係

親密夥伴可以透過工具讀寫和搜尋你的日記，前提是在工具管理裡啟用了對應工具。

日記儲存後會自動嘗試做向量嵌入。萬一失敗，去 RAG 頁點一次 **全量掃描未索引日記** 補上，詳見 [RAG 記憶管理](/zh-tw/docs/configure/rag/)。

日記也是生成週記到年鑑的原材料，逐層怎麼讀見 [回憶與共同回憶](/zh-tw/docs/basics/memories/)。

## 幾個小建議

不用逼自己每天寫長文，三兩句也算。重要的事情加個標籤或收藏，以後篩選和喚醒都好找。另外記得定期確認自己的備份策略，別等出事才想起來。
