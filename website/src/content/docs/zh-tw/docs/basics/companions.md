入口：桌面端在夥伴與對話區，行動端在底欄「夥伴」。

首次啟動後會有一個預設夥伴 Latte，也就是看板娘。你可以再建更多夥伴，每個都有自己的人格和模型設定。Latte 的角色設定和出廠提示詞見 [看板娘 Latte](/zh-tw/docs/basics/latte/)。

## 先搞清夥伴類型

建夥伴時要選類型，這個決定了它能不能碰你的日記。選錯了會出現「為什麼 TA 不能幫我寫日記」這種困惑。

| | 親密夥伴 | 工作夥伴 |
|--|----------|----------|
| 定位 | 陪伴、寫日記、聊回憶 | 辦事、討論，盡量不碰隱私 |
| 日記工具 | 可讀可寫，前提是工具已啟用 | 不能讀寫日記和記憶庫 |
| 記憶與語意搜尋 | 可用 | 相關工具被停用 |

## 夥伴能設定什麼

- 名稱、簡介、頭像（內建或自己上傳）
- 系統提示詞，也就是人格設定
- 綁定專用模型，不綁就用全域預設對話模型
- 設為預設、在側欄置頂（桌面端）
- 上下文輪數，可以有限也可以無限
- 自動壓縮：Token 閾值、保留輪數、壓縮用的提示詞
- 表情包組開關

## 對話裡能做什麼

會話管理方面：新建、重新命名、查看和整理會話列表，隨時切換夥伴或模型。

回覆是串流的，能看到思考過程和工具呼叫，具體取決於模型和你的設定。

訊息可以複製、重新生成、重送，也能 **從此處建立分支**，從某條訊息岔出一條新的對話線。

另外還有快捷指令、會話級的網路搜尋開關（全域那層也得在設定裡啟用搜尋工具）、TTS 朗讀（關閉 / 始終朗讀 / 手動）、自訂聊天背景，以及附件收發。

## 身分卡

在設定裡可以維護自己的暱稱和頭像，還能建多套身分卡，比如工作、旅行各一套，用鍵值條目描述你自己。

對話時注入身分卡，夥伴對你的稱呼和背景認知會穩定很多。

## 夥伴「不記得」我寫過什麼

按順序排查：

1. 日記寫得夠多嗎？內容太少確實沒什麼可搜的。
2. 這是親密夥伴嗎？日記和記憶類工具啟用了嗎？
3. 嵌入模型和 RAG 正常嗎？有沒有提示未索引？見 [RAG 記憶管理](/zh-tw/docs/configure/rag/)。
4. 需不需要用喚醒回憶或共同回憶，直接注入一段較長時間的摘要？見 [回憶與共同回憶](/zh-tw/docs/basics/memories/)。
