---
title: 十分鐘聊起來
description: 設定供應商、選擇模型、開啟 RAG，寫下日記並和夥伴對話。
---

這篇只做一件事：從空白設定走到「問得動日記」。順序是固定的——配金鑰、選模型、確認 RAG、寫一篇、再問夥伴。

截圖來自桌面端簡體中文介面。Android 選單名稱相同，從底欄 **設定** 進去即可。

同步、TTS、聯網搜尋、MCP、自建夥伴、回憶年輪都不在這裡。引導裡的 API 可以跳過，設定完再回來。

## 你需要準備什麼

白守不託管金鑰。最少要兩類模型：一類用來聊天，一類用來把日記做成可檢索的向量。

| 用途 | 建議去哪 |
|------|----------|
| 對話、總結、會話命名 | [DeepSeek 開放平台](https://platform.deepseek.com/) |
| 嵌入（RAG） | [矽基流動](https://siliconflow.cn/) |

一家供應商同時提供對話和嵌入也可以，少設定一家就行。下面按「DeepSeek + 矽基流動」來示範，國內比較好申請。

## 1. 打開設定

側欄底部點 **系統設定**。如果你已經把「供應商管理」釘到側欄，也可以直接點進去。

![側欄底部的系統設定](/assets/images/docs/quickstart/01.png)

*側欄底部「系統設定」。新使用者預設側欄不一定能直接看到供應商入口，走設定最穩。*

## 2. 拿到對話用的 API Key

打開 [DeepSeek 開放平台](https://platform.deepseek.com/)，進入 **API keys**，點 **建立 API key**。完整金鑰只在建立時顯示一次，複製後回到白守貼上。

![DeepSeek 開放平台的 API keys 頁](/assets/images/docs/quickstart/04.png)

*在 DeepSeek 控制台建立金鑰。不要把完整 Key 發到任何地方。*

## 3. 設定 DeepSeek

打開 **設定 → 供應商管理**，左側點 **DeepSeek**。

1. 右上角開關打開。沒開等於沒用。
2. 把 Key 填進 API 設定。Base URL 一般不用改。
3. 點 **獲取模型**，在列表裡打開要用的對話模型。
4. 點 **測試連線**，彈窗裡選對話模型，不要選 Embedding、Rerank 或 TTS。
5. 點底部 **儲存修改**。這步最容易漏。

![供應商管理中的 DeepSeek](/assets/images/docs/quickstart/02.png)

![先獲取模型，再測試連線](/assets/images/docs/quickstart/03.png)

*按圖上的 1、2：先獲取並勾選模型，再測連線。列表是空的話，測試會沒有可選的對話模型。*

## 4. 拿到嵌入用的 API Key

打開 [矽基流動](https://siliconflow.cn/)，先完成實名認證，再到帳戶管理裡的 **API 金鑰** 建立 Key。

嵌入模型稍後在白守裡勾選，不用在網頁上單獨「開通 RAG」。

![矽基流動控制台：先實名，再拿 API Key](/assets/images/docs/quickstart/05.png)

*先實名，再打開「API 金鑰」。模型廣場只是目錄，真正啟用發生在白守裡。*

## 5. 設定矽基流動

回到 **供應商管理**，左側點 **矽基流動**，同樣走一遍：開開關 → 填 Key → **獲取模型** → 只打開嵌入模型 → **儲存修改**。

列表可能有幾十上百個。用搜尋框找名字裡帶 `embed` / `embedding` 的，例如 `Qwen/Qwen3-Embedding-8B`。聊天模型在這裡不必打開。

![矽基流動已啟用嵌入模型](/assets/images/docs/quickstart/06.png)

:::caution[聊天模型和嵌入模型不是一類]
只設定 DeepSeek、不設定嵌入，夥伴能聊，但搜不到日記細節。語意搜尋依賴嵌入模型。
:::

## 6. 分配全域預設模型

打開 **設定 → 全域預設模型**。供應商裡勾過的模型，這裡才能選到。

| 卡片 | 必配？ | 選什麼 |
|------|--------|--------|
| 預設對話模型 | 必配 | DeepSeek 的對話模型 |
| 嵌入模型 (Embedding) | 必配 | 矽基流動的嵌入模型 |
| 記憶總結模型 | 建議 | 可與對話同一家 |
| 預設命名模型 | 可後配 | 小模型即可，用來幫會話取標題 |

點卡片上的選擇器分配。嵌入那一張最容易漏，介面上也會特別標出來。

![四類全域預設模型都已分配](/assets/images/docs/quickstart/07.png)

TTS 在另一頁，先不用管。更換嵌入模型時如果跳出「更換嵌入模型？」，新使用者沒有舊向量，確認即可。已經有日記向量時不要隨便換，詳見 [RAG 記憶管理](/zh-tw/docs/configure/rag/)。

## 7. 確認 RAG 開著

打開 **設定 → RAG 記憶管理**。

- 標題旁的開關打開。預設就是開的；關掉會出現「RAG记忆功能已经关闭了喵~」。
- 標題下面那一行 **模型:** 應是你剛選的嵌入模型，不能是「未配置(点击跳转)」。
- 日記向量可以還是 0，下一步再寫日記。
- **檢索參數調節** 先別動。閾值調太高會搜不到。

![RAG 已開啟，嵌入模型已顯示](/assets/images/docs/quickstart/08.png)

## 8. 寫一篇日記

關掉設定，點 **+ 寫日記**。留下一件之後能問出來的事——吃了什麼、去了哪裡、今天心情怎麼樣都可以——然後儲存。

儲存後會自動嘗試嵌入。失敗的話，介面會提示你去 RAG 頁補掃。

![日記列表裡已經有內容](/assets/images/docs/quickstart/09.png)

## 9. 確認日記進了檢索庫

再打開 **RAG 記憶管理**。若 **日記向量** 還是 0，點 **全量掃描未索引日記**。掃完後，下方列表出現日記、**日記向量** 大於 0，這一步就完成了。

![RAG 中已出現日記向量](/assets/images/docs/quickstart/10.png)

也可以在搜尋框裡切到 **語意搜尋**，用日記裡的詞試一下。搜得到就表示嵌入是通的。

## 10. 問 Latte

打開頂部 **夥伴**。預設夥伴是 **Latte**，類型為 **親密夥伴**。新建對話，直接問日記裡的事，例如「我最近吃了什麼？」。

回覆裡如果展開看到 **日記搜尋**、**語意搜尋**，表示記憶檢索已經在工作。

![向 Latte 提問並檢索到日記](/assets/images/docs/quickstart/11.png)

:::tip[必須是親密夥伴]
工作夥伴預設不能讀寫日記，也用不了語意搜尋。這是設計如此。夥伴類型見 [AI 夥伴與對話](/zh-tw/docs/basics/companions/)。
:::

對話模型需要支援工具呼叫。剛寫入的向量偶爾有幾秒延遲，搜不到就再問一次，或回 RAG 頁看向量數。

## 最容易漏的幾步

1. 供應商右上角開關沒開。
2. 獲取模型後沒有勾選。
3. 沒點 **儲存修改**。
4. 全域預設模型只設定了聊天，沒設定 **嵌入模型**。
5. RAG 標題旁的開關被關掉。
6. 還沒寫日記就問「你記得我嗎」。
7. 用工作夥伴去問日記。
