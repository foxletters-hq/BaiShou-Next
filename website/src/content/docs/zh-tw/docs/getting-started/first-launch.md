第一次開啟白守會走一遍引導，大約七步。之後都能在設定裡改，但語言和儲存位置建議一開始就選好。

## 引導會問你什麼

| 步驟 | 你在做什麼 |
|------|------------|
| 選擇語言 | 介面語言。預設夥伴 Latte 也會按這個語言建立 |
| 歡迎 | 認識一下白守 |
| 書寫我們的回憶 | 說明日記是整套記憶的錨點 |
| 複製共同回憶 | 了解週記、月報、季報、年鑑是怎麼來的 |
| 選擇儲存位置 | 資料存在哪裡 |
| API / 供應商 | 模型金鑰由你自備，可以跳過 |
| 保護您的隱私 | 本地處理的說明 |

走完進主介面，此時已經有一個看板娘夥伴 Latte。

## 儲存位置怎麼選

桌面端選一個你記得住、方便備份的資料夾當儲存根目錄就行。

Android 預設存在應用程式沙盒裡。想和桌面的目錄結構對齊，可以啟用外部的 `BaiShou_Root`，這通常需要更高的儲存權限。

兩者的區別和風險詳見 [工作區與資料位置](/zh-tw/docs/configure/workspace/)。

## API 可以稍後再設定嗎

可以，引導裡直接跳過。之後按 [十分鐘聊起來](/zh-tw/docs/getting-started/quick-start/) 設定供應商、選模型、打開 RAG，就能開始對話。

不過要知道會缺什麼：沒有對話模型，夥伴聊不了；沒有嵌入模型，日記的自動嵌入和語意搜尋會不正常。完整對照見 [設定 AI 供應商與模型](/zh-tw/docs/configure/ai-providers/)。

## 從舊版升級上來的

如果你是從舊版 Flutter 白守覆蓋安裝的，啟動後可能會看到 **版本遷移** 提示。請按 [從舊版白守遷移](/zh-tw/docs/migrate/from-legacy/) 一步步來，先別急著刪舊的資料目錄。
