白守是一款開源的、本地優先的 AI 記憶陪伴軟體。

你在本地寫下日記和生活片段，白守把它們逐層總結成「回憶年輪」，再交給 AI 夥伴長期理解、檢索和陪伴。資料不進某個雲端帳號，留在你自己的裝置上。

> 以純白誓約，守護彼此一生。

## 它能做什麼

| 能力 | 說明 |
|------|------|
| 日記與回憶年輪 | Markdown 書寫，逐層凝結為週記、月報、季報、年鑑長程記憶 |
| 人生關係圖譜 | 內建實體關係圖資料庫，自動化梳理人物關係網路與時間因果脈絡 |
| 自主 AI Agent | 具備規劃與工具呼叫能力，支援 MCP 開放協定無縫連接外部生態 |
| 專屬 AI 夥伴 | 多夥伴人格自訂與獨立模型綁定，在長期共同記憶之上自然對話與陪伴 |
| 混合 Graph RAG | 全文檢索、向量檢索與圖譜多跳推理相結合，深層穿透個人記憶 |
| 工作空間與多端同步 | 隔離的多工作區，支援端對端加密同步與自建 S3 / WebDAV 備份 |

:::tip[圖資料庫與 Agent 能力全面就緒]
白守現已全面引入嵌入式實體關係圖資料庫與自主 Agent 智慧體系統，不僅能記錄生活隨筆，還能將日常對話與瑣碎記憶編織成可互動、可推理的立體網路。
:::

## 和 Notion、Obsidian 有什麼不一樣

筆記工具解決的是「資料放得整齊」，白守想解決的是「AI 真的記得你」。

| | 筆記工具 | 白守 |
|--|----------|------|
| 重心 | 整理、雙向連結、寫作 | 被 AI 長期理解和使用的個人記憶 |
| AI | 多是外掛或外接的對話框 | 夥伴、回憶年輪、RAG 就是產品骨架 |
| 資料 | 常依賴官方雲端或外掛生態 | 預設在本地，可選同步到你自建的 S3 / WebDAV |

## 我們堅持的幾件事

1. **本地優先**：核心資料在你的裝置上，隨時能匯出、能帶走。
2. **核心能力開放**：日記、自建同步、自訂模型 API 不設付費牆。
3. **讓 AI 讀懂你的資料**：能檢索、能問答、能總結，而不只是個雲端硬碟。
4. **官方服務只是選項**：想省事可以用，不付費同樣能完整使用。
