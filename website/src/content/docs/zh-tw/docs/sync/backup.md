需要「整包帶走」或者「出事能回滾」的時候，用備份，別用增量同步。

## 有哪幾種

| 能力 | 說明 |
|------|------|
| 本地 ZIP 備份 | 匯出和匯入完整備份包 |
| 雲端備份 | 把全量包放到 S3 或 WebDAV，路徑和增量同步分開 |
| 本地快照 | 重大操作前自動保護，觸發條件隨版本 |
| 區域網路傳輸 | 同一 Wi-Fi 下裝置間整庫互傳 |

## 匯出的習慣

定期做本地 ZIP，並且複製到第二個地方，比如行動硬碟或另一個雲端硬碟。只放一份不叫備份。

大版本升級或遷移之前，先備份一次。

匯入前確認目標裝置空間夠，並且把覆蓋提示看完。

## 匯入要留意

匯入可能覆蓋現有資料，提示別一路點確定。

從舊版上來優先走 [版本遷移](/zh-tw/docs/migrate/from-legacy/)，不要指望隨手解壓一個目錄就完事。

匯入完如果夥伴突然「失憶」，去 RAG 頁做一次 [全量掃描](/zh-tw/docs/configure/rag/)，通常是向量庫沒跟上。

## 附件

**附件管理** 裡能看日記附件和會話附件，也能清理孤立檔案。清理前確認沒有還在被引用的內容。
