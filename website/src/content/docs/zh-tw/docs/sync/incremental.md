增量同步用來在你的裝置和自建雲（S3 或 WebDAV）之間，按檔案做增量對齊。改了哪些傳哪些，不是整包搬。

## 怎麼跑一次

1. 設定遠端：端點、儲存桶或路徑、金鑰。
2. 點 **預覽計畫**，看清這次會動哪些檔案。
3. 確認沒問題再執行同步。

第一次用之前，建議把用戶端內的同步說明和風險提示讀一遍。

同步範圍通常包括日記、回憶總結、會話、夥伴、附件、部分設定目錄，以及工作區註冊資訊。

:::caution[和全量備份不是一套]
- 雲端路徑預設是分開的，增量常用 `memories_sync` 這類目錄。
- 覆蓋範圍也不同，是否包含完整資料庫和向量快取不一樣。
- 千萬不要把兩套功能指向同一個目錄，然後交叉覆蓋。

區別詳見 [三種方式怎麼選](/zh-tw/docs/sync/overview/)。
:::

## 分端建議

桌面端可以放心雙向，同時建議開著 [Git 版本控制](/zh-tw/docs/advanced/desktop/) 方便回滾。

行動端網路和權限都更脆，務必先看預覽計畫。遇到衝突先備份再同步。

另外別讓各端應用程式版本差得太遠，容易出奇怪的問題。

## 金鑰會跟著走

如果同步範圍包含設定目錄，API Key 就可能進到雲端。請限制那個儲存桶或目錄的存取權限，也別在不可信的裝置上把完整設定拉下來。
