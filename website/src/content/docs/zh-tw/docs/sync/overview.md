白守裡有好幾套「把資料挪到別處」的能力，名字看著都像同步，用途其實差挺遠。把雲端路徑混在一起、或者搞錯覆蓋範圍，是最常見的翻車原因。

## 四種能力對照

| 方式 | 做什麼 | 什麼時候用 | 要注意 |
|------|--------|------------|--------|
| 增量同步 | 按檔案做增量對齊，覆蓋日記、總結、會話、夥伴、附件和部分設定 | 多台裝置持續同步到自建 S3 / WebDAV | 雲端路徑和全量備份不同，且可能包含含金鑰的設定 |
| 資料備份 | ZIP 全量匯出匯入，或者往雲端放全量包 | 換機、災備、階段性封存 | 路徑和範圍都和增量不同，別當同一套用 |
| 區域網路傳輸 | 同一個 Wi-Fi 下整庫互傳 | 桌面和手機之間快速搬家 | 需要同一網路，注意別搞反方向 |
| 版本控制 | 桌面端對儲存根做 Git 提交和推送 | 想要歷史版本和回滾 | 僅桌面端，可以和增量同步互補 |

## 按需求選

只想留條後路，就用本地 ZIP 全量備份，定期拷到別的地方。

兩台裝置日常要對齊，用增量同步到你自己的 S3 或 WebDAV，桌面端建議再開 Git 兜底。

偶爾換機重裝，走全量備份匯入，或者區域網路直接傳。

行動端建議當單向備份用，或者雙向時格外小心。手機的權限和背景限制比桌面多。

## 一個安全提醒

增量同步的範圍可能包含 `.baishou/settings/` 這類設定目錄，裡面可能有 API Key。所以：

- 用私有儲存桶或私有 WebDAV，權限給到最小
- 別把同步目標設成公開可讀的位址
- 共用電腦上先想清楚風險再同步
