---
title: Desktop vs mobile
description: Differences between Windows desktop and Android mobile in navigation, features, and storage.
---

Both platforms share the core capabilities: diary, memories, companions, RAG, and sync. The differences are mostly in the shell and a few advanced features.

## Side by side

| Dimension | Desktop (Windows) | Mobile (Android) |
|-----------|-------------------|------------------|
| Navigation | Customizable sidebar | Bottom bar: Diary / Companions / Memories / Settings |
| Git version control | Yes | No |
| MCP service | Yes, plus a legacy `/sse` compatibility endpoint | Android has it too, `/mcp` only |
| Global shortcuts | Yes | No |
| Search engine options | 7, including Bing and Google local search | 5, no local search |
| Storage location | A folder you choose | App sandbox, or an external `BaiShou_Root` |
| Official package | Windows installer | APK |

## How to combine them

Use desktop for serious writing and when you want Git as a safety net.

Use your phone for quick notes and browsing whenever.

For picking a sync method, see [Which method to use](/en/docs/sync/overview/). Mobile is better suited to one-way backup, or bidirectional with extra care.
